01

The CAPTCHA, inverted

The web spent twenty years building ways to keep bots out. Now more and more work is meant to be done by agents: booking, filling forms, running workflows. A service that wants agent traffic has no way to check that what claims to be an agent really is one, and that a person didn't quietly do the work.

CAPTCHA
✓I am not a robot

Proves a human is present. Built to keep automation out.

AgentCAPTCHA
✓This was done by an agent

Proves the task ran autonomously. Built for services that want automation in.

02

Proof of autonomous execution

The agent runs its task through an SDK that produces a proof of how the task was executed. A separate verifier checks that proof and returns a pass or a reject. The service never has to trust the agent's own claim.
